# Personal Portfolio

Personal portfolio website of Yusra Manal, made for Assignment-1 of Full Stack Development
(B.E. CSE, VII Semester) at Stanley College of Engineering and Technology for Women.

## Technologies used

- HTML5
- CSS3 (Flexbox, Grid, media queries)
- Bootstrap 5
- JavaScript (ES6+)

## Sections

Home, About, Education, Skills, Experience, Projects, Achievements and Contact.

## Features

- Responsive layout that works on mobile, tablet and laptop
- Dark mode / light mode button
- Project filter by category
- Contact form validation with error and success messages

## Folder structure

```
index.html
css/style.css
js/script.js
assets/logo.svg
README.md
```

## How to run

Download the repository and open `index.html` in a browser.
