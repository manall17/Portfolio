# Personal Portfolio

**Live site:** https://manall17.github.io/Portfolio/

Personal portfolio website of Yusra Manal, made for Assignment-1 of Full Stack Development
(B.E. CSE, VII Semester) at Stanley College of Engineering and Technology for Women.

It is a single-page, responsive website that shows my education, skills, experience,
projects and achievements, with a contact form at the end.

## Technologies used

| Technology | Used for |
| --- | --- |
| HTML5 | Semantic structure (header, nav, main, section, footer), lists, table, links, image and form |
| CSS3 | Baby blue theme with CSS variables, Flexbox, Grid and media queries |
| Bootstrap 5 | Navbar, grid, cards, table, form, buttons, list groups and alerts |
| JavaScript (ES6+) | Arrow functions, arrays of objects, loops, DOM manipulation and event handling |

## Sections

- **Home** - my name, a short tagline and links to my projects and contact form
- **About** - a short introduction, course details and how I like to work
- **Education** - my academic details in a table
- **Skills** - technical skills in four groups, and key skills
- **Experience** - my internships and current role
- **Projects** - project cards that can be filtered by category
- **Achievements** - awards, certificate courses and activities
- **Contact** - email, LinkedIn and a contact form

## Features

- Responsive layout that works on mobile, tablet and laptop (mobile-first CSS with media queries at 576px and 992px)
- Dark mode / light mode button
- Project filter by category, with a count of the projects shown
- Contact form validation with error and success messages
- Sticky navbar that collapses into a menu button on small screens
- Accessibility: skip-to-content link, labels for all form fields and alt text for the image

## Folder structure

```
index.html        page structure and content
css/style.css     colours, layout and responsive styles
js/script.js      theme button, project filter and form validation
assets/logo.svg   logo used in the navbar
README.md
```

## How to run

Open the live site: https://manall17.github.io/Portfolio/

Or run it on your computer:

1. Download this repository (Code > Download ZIP) and extract it.
2. Open `index.html` in a browser.
